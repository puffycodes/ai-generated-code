# Flask Web Server

A simple Flask web server with message submission functionality.

## Setup

1. Install Flask:
   ```bash
   pip install flask
   ```

2. Run the server:
   ```bash
   python app.py
   ```

3. Open your browser to `http://localhost:5000`

## Features

- Home page with welcome message
- Message submission form with email and message fields
- Result page displaying submitted information
- CSS styling for all pages
- Navigation links between pages
