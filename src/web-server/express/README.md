# Express Web Server

A simple Express.js web server with message submission functionality.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

3. For development with auto-restart:
   ```bash
   npm run dev
   ```

## Usage

- Visit `http://localhost:3000` for the home page
- Click "Submit Message" to access the submission form
- Submit email and message to see the confirmation page

## Features

- Home page with welcome message
- Message submission form
- Confirmation page displaying submitted data
- CSS styling for all pages
- Navigation links between pages
